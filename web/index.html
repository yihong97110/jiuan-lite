① 标 · 数据准备

清洗 / 去重 / 统一为 chat 格式，并切分 train/valid。source 是本轮新增数据来源，可选项目内 jsonl 文件或已有数据集；parent 是历史父数据集，用于增量迭代。

标 · 任务

标 · 蒸馏生成

调用外部大模型API，自动生成50条多类型问答对（概念解释/原理机制/流程步骤/案例分析等10类×5条），直接保存为可训练数据集。

蒸馏 · 任务

② 训 · SFT / LoRA 训练

选择基座模型与数据集，默认用 LLaMA-Factory + LoRA 在 GPU 上训练；device 选 cuda（本机无 GPU 时自动回退 CPU 并告警）。

训 · 任务

③ 推 · 推理

选择模型（base 或已训练模型），输入 prompt 生成回答，并记录 token 计量。

推 · 任务

④ 评 · 评测

在 valid 切分上评测 ROUGE-L / BLEU（mock 或 train 切分的指标标注为不可靠）。

提示：Judge 默认开启。API Key 已存 .env，留空即可直接评测。切换平台/模型请重新填写。

验证集广度 · Judge 分析

展示 Agent/数据源自动扩展出的广度验证集，以及 judge 对各类别覆盖面的评分结果。judge 负责发现广度问题，不把训练样本写回 held-out 验证集。

点击刷新查看验证集广度。

评 · 任务

⑤ 迭代 · 数据驱动迭代闭环

对标久安「数据驱动迭代」：按数据集血缘(parent)分组，展示每一轮 v1→v2→… 的数据量/loss/指标变化。在④评测后会自动给出薄弱点(gap)建议，指导下一轮该补什么数据。

点击刷新查看迭代链。

④ 历史评测薄弱点(全部保留，从新到旧，标注迭代)

点击上方“刷新迭代看板”加载全部历史建议。

⑥ 知识库 · RAG 检索增强

弥补 SFT “硬记”不足：上传应急法规/预案文档入库，提问时先检索相关条文再注入上下文生成。当前离线默认 TF-IDF 嵌入（零下载），装 sentence-transformers+bge 可升级语义检索。

点击「刷新集合」查看所有知识库。

RAG 提问

知识库缺口

系统自动记录"检索未命中(最高分低于阈值)"的问题。业务人员点「补充知识」贴入权威条文，一键入库后下次提问即命中，无需手动找文件。

点击「刷新缺口」查看。

⑦ 标注 · 薄弱点回灌闭环

gap 分析 → 生成标注任务 → 浏览器内直接标注 → 回灌为训练集(可选硬样本加权/parent增量) → 一键触发训练。全程无需编辑 jsonl。

标注覆盖度

一眼看出哪些类别/迭代还没补完（覆盖率低的排前面）。

点击「刷新覆盖度」查看。

标注任务列表

浏览器内标注

选任务→加载，直接在下方填写答案→保存。无需打开 jsonl 文件。

先选任务并点「加载标注」。

回灌为训练集

填好答案后选任务回灌。硬样本加权=知识缺失类样本在训练集内复制倍数；勾选自动训练则回灌后立即排训练。

跨版本 gap 解决追踪

每次回灌解决了哪些薄弱点，及其在回灌前后评测里的 judge/ROUGE 变化。

点击「刷新追踪」查看。

回灌效果验证 · 查缺补漏

从回灌样本生成同主题但不同问法的 impact held-out 验证题，对比回灌前/后模型；未改善项自动生成补漏标注任务，可继续回灌训练。

点击「验证回灌效果」生成 impact 验证集并对比前后模型。

⑧ Agent · 自动迭代机器人
